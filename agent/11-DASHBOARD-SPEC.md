# Dashboard Specification

## Navigation
- Overview
- Customers
- Pass Templates
- Active Passes
- Loyalty
- Analytics
- Team
- Integrations
- Settings

## Overview
Show relevant organization metrics such as:
- customers
- active passes
- wallet installations
- loyalty activity
- redemptions
- recent activity

## Customers
Support:
- search
- filter
- create
- view
- edit
- pass history
- loyalty history

## Passes
Support:
- template creation
- template editing
- activation/archive
- customer pass creation
- Apple delivery
- Google delivery
- status

## Analytics
Show time-based and operational metrics derived from analytics events.

Do not expose another tenant's data.
